# AAR — பத்திரம் எழுதும் அலுவலகம்

A complete public website and secure admin panel for AAR, a document registration office in Panagudi (பனகுடி), Tamil Nadu.

## Features

### Public Website
- Modern, mobile-responsive design with Tamil-friendly typography
- Six dedicated service request forms:
  1. Document Registration (பத்திர பதிவு)
  2. Marriage Registration (திருமண பதிவு)
  3. Encumbrance Certificate / EC (வில்லங்கச் சான்று)
  4. Document Copy (ஆவண நகல்)
  5. Birth/Death Certificate (பிறப்பு/இறப்பு சான்று)
  6. Patta/Chitta (பட்டா சிட்டா)
- Document file upload on every service form
- Appointment booking with date/time slot selection
- Call and WhatsApp quick-contact buttons
- Contact form and embedded map

### Admin Panel
- Secure email/password authentication (Supabase Auth)
- Dashboard with live stats and recent activity
- Customer management with full history (requests, appointments, payments, documents)
- Service request & appointment management with status workflows
- EC management with certificate file upload
- Documents gallery
- Payment tracking with revenue summaries
- Auto-generated notifications feed
- Reports & analytics with service breakdown and monthly trends
- Settings to manage business info and admin users

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Supabase (database, auth, storage)
- Lucide React icons
